# 长篇小说创作协作（novel-writing）

> 本技能把网文创作中六类专业分析工作拆分给**只读子代理**，由主 AI 统一编排、
> 汇总与落库。子代理不写任何作品数据，产出一律为**建议态**。
> 六角色的完整提示词、委派协议与收敛规则放在 `references/`，本文件只常驻这一份索引。

## 何时使用本技能

- 展开卷/章/节细纲、黄金三章、剧情规划 → 派发 `outline`
- 生成/丰满人物卡、推导人物关系 → 派发 `character`
- 伏笔埋设计划、回收检查、闲置预警 → 派发 `foreshadow`
- 去 AI 味、句式节奏、文风统一的精修 → 派发 `polish`
- 逻辑漏洞/人设崩塌/节奏问题的审读 → 派发 `review`
- 正文对资料库/前后的设定冲突与查重 → 派发 `consistency`
- 多角色结果需要汇总、冲突仲裁、迭代收敛 → 读 `references/convergence.md`

## 六角色索引（references/）

| 角色 | reference | 何时派发 | 核心产出 |
|---|---|---|---|
| 大纲代理 | `references/outline.md` | 需要细纲/分卷/黄金三章/下一章写什么 | 卷/章/节三级细纲，带爽点、反转、伏笔挂载点 |
| 人物代理 | `references/character.md` | 建人物卡、丰满、推导关系 | 结构化人物卡 + 带证据的关系边建议 |
| 伏笔代理 | `references/foreshadow.md` | 排埋设、查回收、闲置预警 | 埋设计划 + 回收检查 + 闲置预警 |
| 润色代理 | `references/polish.md` | 去 AI 味、精修、文风统一 | 逐条修改建议 + 人性化改写稿 |
| 审读代理 | `references/review.md` | 发布前检查、挑错、质量审读 | 分级问题清单 + 通过/不通过/无法判断结论 |
| 一致性代理 | `references/consistency.md` | 设定冲突、前后矛盾、查重 | 双方并列的冲突清单 + 重复段落 |

配套契约（**派发前必读对应项**）：

- `references/delegation.md`：**委派协议**——`subagent_task` 的 TaskArgs 字段、
  如何写自包含 `task`、如何用 `context` 递材料、result 返回结构、异步 `wait` 语义、
  零写纪律。**任何派发前先读本文件。**
- `references/convergence.md`：**收敛协议**——权威源优先级（P0–P4）、冲突仲裁、
  去重、3 轮收敛、升级路径。多角色汇总时读。
- `references/style-tokens.md`：**文风令牌**——禁词表、句式节奏、对话/感官/章末钩子规范。
  派发 `polish` 或撰写/润色正文时作为文风基线注入 `context`。

## subagent_task 派发总则

六角色统一走基座原生 `subagent_task` 工具（工具名即 `subagent_task`，见
`references/delegation.md`）。要点如下，细节以 delegation.md 为准：

1. **一角色一派发**：每次 `subagent_task` 调用只跑一个角色。先读该角色的 reference，
   把其中「任务说明（派发时粘贴）」段连同本次具体任务，写进 `task`；把原始材料
   （章节正文、既有大纲、资料卡、文风令牌等）逐字放进 `context`。
2. **task 必须自包含**：子代理是隔离的隐藏子会话，**看不到主对话、没有记忆**。
   `task` 要写成给刚进门的同事的完整交代：目标、成功判据、材料在哪、约束、
   以及**精确要求返回什么**。不要把「见上文」「按之前说的」写进去。
3. **材料只给真实数据**：新基座没有旧的 `novel_*` 数据预取工具（这些工具已不存在）。
   材料一律由主 AI 用**当前可用的工具**（含 `novel_memory_text` / `novel_memory_link` /
   `novel_memory_graph` 三个记忆工具）或用户提供的原文取得，逐字放进 `context`；
   取不到就留空并在 `task` 里注明「缺少：xxx」，**禁止编造材料填充**。
4. **零写纪律**：子代理只读、只产建议。落库、改稿、改状态一律由主 AI 在子代理
   返回后显式执行；子代理不得声称「已保存/已写入」。
5. **按需选 wait**：后续步骤必须依赖结果时 `wait=true`（阻塞取回）；否则 `wait=false`
   （异步，结果以新消息送达）。**不要轮询**结果消息。
6. **模型档位**：`model_choice` 默认 `same_as_me`；仅当任务确需更强推理用
   `default_model`，纯机械可核验任务用 `sub_model`。
7. **收敛**：多角色结果按 `references/convergence.md` 汇总；同一任务最多迭代 3 轮，
   第 2 轮起在 `task` 里粘贴上一轮结果要求在旧址上优化，不推倒重来。

## 边界与纪律

- 本技能只负责「分析/建议」，写正文、改稿、改数据由主对话按正常工具流程完成。
- 角色之间不互相调用；一切派发、汇总、裁决、落库收在主 AI 一处。
- 冲突不私了：子代理与权威源、子代理之间的冲突按 `convergence.md` 显式仲裁，
  子代理只上报不裁决。
